# Words

A voice-only language app for a toddler who can't read yet. No text on screen,
no menus, no scores. She taps one big picture, hears a word, says it back, and
the app plays a soft chime if she got it. It teaches English, Slovak, Czech,
and Italian at once, cycling through the same 30 objects in all four, and
quietly repeats whichever words she's been missing.

It's a plain web page (`web/`) rather than a native app — see
[`web/README.md`](web/README.md) for how to run it, add your own voice
recordings, and known limitations.
